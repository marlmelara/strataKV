# Glossary additions

Terms that come up in the real code and are not already in the build spec's "Glossary" tab.
Each phase appends the terms it introduced.

## P0

| Term | Plain-English meaning | Where it shows up |
| --- | --- | --- |
| Advisory lock (`flock`) | A lock the OS records but does not enforce: it only works because every cooperating process asks first. Enough to stop two StrataKV processes opening one database; no defense against a process that never checks | `Env::LockFile`, the `LOCK` file |
| Compilation database | `compile_commands.json`, a list of every source file and the exact flags used to compile it. Tools like clang-tidy need it to analyze code the same way the compiler saw it | Generated by CMake, used by the CI lint job |
| File descriptor | The small integer the OS gives you to refer to an open file. Python exposes it as `f.fileno()` | `fd_` in `PosixWritableFile` |
| `FetchContent` | A CMake feature that downloads a dependency's source at configure time and builds it as part of your project. Avoids a vendored copy or a git submodule to keep in sync | How GoogleTest arrives |
| fsyncgate | The 2018 discovery that on Linux a failed `fsync` may leave the kernel having already dropped the dirty pages and cleared the error, so a retry reports success while the data is gone. Postgres now treats `fsync` failure as fatal | Why `PosixWritableFile` makes a sync failure sticky |
| Known-answer test | A test that checks an algorithm against a published, externally agreed-upon output rather than against whatever the code currently does. The only kind of test that can catch a checksum implementation being self-consistently wrong | `Crc32c.MatchesKnownAnswers` |
| Out-of-source build | Keeping all compiler output in a separate directory (`build/`) instead of beside the sources, so several configurations can coexist and the tree can be wiped by deleting one folder | One directory per preset: `build/debug`, `build/asan`, ... |
| Page cache | The OS's in-memory copy of recently used file contents. A plain `write` only reaches here; `fsync` is what pushes it onward to the drive | Why `Append` returning OK does not mean "durable" |
| Position-independent code (PIC) | Machine code that works regardless of where in memory it is loaded. Required for anything linked into a shared library, which is what a Python extension module is | `POSITION_INDEPENDENT_CODE ON` on the engine library |
| scikit-build-core | The Python build backend that makes `pip install .` run CMake and place the compiled `.so` inside the Python package | `pyproject.toml`, `[tool.scikit-build]` |
| Short write | When `write()` accepts fewer bytes than you asked for, which is legal and must be looped over. Ignoring it silently truncates data | `WriteFully` in `src/env.cc` |
| Translation unit | One `.cc` file plus everything it includes — the unit the compiler actually processes. Explains why a header included twice would be an error without `#pragma once` | Every `.cc` in `src/` |

## P1

| Term | Plain-English meaning | Where it shows up |
| --- | --- | --- |
| Acquire load | A read of an atomic that also guarantees you see everything the writer wrote before its release store | `FindGreaterOrEqual` |
| Arena (bump allocator) | Hands out pieces of big blocks by advancing a cursor, and frees every block at once. No individual frees, which is what makes lock-free reads safe | `src/arena.h` |
| Internal key | A user key plus an 8-byte trailer of sequence number and type. What is actually stored and sorted | `src/internal_key.h` |
| Placement new | Constructing an object in memory you already own, instead of allocating | `SkipList::NewNode` |
| Publication | The single release store that makes a fully built node reachable by readers | `SkipList::Insert` |
| Release store | A write to an atomic that publishes everything written before it to any acquire load that sees the value | `SkipList::Insert` |
| Sequence number | A monotonically increasing counter stamped on every operation. It is what "newer" means, and what a snapshot is measured against | Assigned in `DBImpl::Write` |
| Snapshot | A sequence number a read is pinned to, so writes newer than it stay invisible | `DBImpl::Get` |
| Torn record | A WAL record only partly written when the process died. Normal after a crash, never an error, because it was never acknowledged | `WalReader::Replay` |
| Trailer | The 8 bytes appended to every user key: 7 of sequence number, 1 of type | `PackSequenceAndType` |
| WriteBatch | A group of operations that becomes one WAL record with one checksum, so it replays entirely or not at all | `include/stratakv/write_batch.h` |
